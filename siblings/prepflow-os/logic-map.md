# 🛡️ PrepFlow OS: Logic Map (The Protocol)
**Goal:** Transform multichannel chaos into a structured inventory and prep plan.

## 🟢 STAGE 1: INBOUND SIGNAL (The Input)
*The system listens for data from these "Clinical Sites":*
- [ ] WhatsApp Business Message
- [ ] Instagram/Facebook DM
- [ ] Website Order Form

**Rule:** If a message contains a quantity (e.g., "50 packs") or a date (e.g., "Saturday"), it is flagged as a **High-Priority Signal**.

## 🟡 STAGE 2: THE PREP FILTER (The AI Brain)
*Gemini processes the raw text and extracts these variables:*
1. **Subject:** Who is asking?
2. **Order:** What exactly do they want?
3. **Timeline:** When is the deadline?
4. **Resources:** What ingredients/materials are needed?

**PLATEWORK Check:** Use "Signal Reveal" (Coral color) to highlight if any information is missing (e.g., no delivery time provided).

## 🔴 STAGE 3: INVENTORY SYNC (The Shield)
*The system compares the Order against the "Stockroom":*
- **Action:** Subtract required ingredients from the current inventory.
- **Alert:** If stock is low, generate a "Restock Task" automatically.

## 🔵 STAGE 4: PEACE OF MIND (The Output)
*The final "Validated" result for the business owner:*
- **Task Card:** A modular card snaps into the "Saturday" calendar.
- **Confirmation:** A pre-written message is ready to send back to the customer.
- **Dashboard:** The "Shield" updates to show the day is fully planned.
